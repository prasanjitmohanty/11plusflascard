# Brightlane — offline UK 11+ preparation

This original Maths and English preparation toolkit is tailored to common
formats for **Tiffin Girls', Nonsuch and Wallington High School for Girls**,
with a school-linked guide for both stages. The current guide is for the
**September 2028 entry cycle**, whose exams are expected in autumn 2027; check
each school's latest admissions information before acting. A 2027 preparation
label is not a universal entry year, syllabus, or promise that formats and
arrangements will remain unchanged.

The scenario bank below offers **original exam-style situations** in familiar
Maths and English preparation formats. It is **not an archive of actual past
papers from 2017–2026**: no historical year or school/provider is attributed
to any scenario. This site is not a complete national archive of 11+ papers
and no licensed historic papers were supplied to reproduce. Use the scenarios
as new practice, not as evidence of what appeared in a particular past exam.

A standalone, responsive Maths and English study website. It has **30 lessons,
30 worked examples and 90 lesson-practice questions**, plus **60 separate test
questions** and **12 longer-comprehension questions**. **32 original scenarios**
(16 per subject), with 64 explained subquestions, bring that foundation bank to
**226 unique questions**. The school-format banks add 65 SET Maths and 68 SET
English questions, 30 written Stage 2 Maths problems, 16 Stage 2 comprehension
questions, 24 Tiffin-style digit-entry items and 20 unfamiliar-format Maths
items: **449 unique question tasks across the site** (excluding eight writing
prompts and reused worksheet items). The saved practice/progress registry
contains **403** questions; some lesson and print-material items are presented
outside that registry. There are **154 flashcards**: 60 general topic cards and
94 school/exam-format cards. The Study materials library adds 30 topic revision sheets,
30 concise subject reference cards, three original longer passages, six writing
prompts with planning scaffolds and self-checks, and printable three-question
worksheets for all 30 topics (the worksheet questions reuse the original lesson
bank). A local
evidence dashboard, saved results, targeted revision, optional timer, user-set
study planner and validated progress backups complete the toolkit. All passages
and questions are original. There are no accounts, adverts, runtime
dependencies, external fonts, analytics or network requests.

## Open offline

1. Download and extract the complete website ZIP, or copy this repository folder.
2. Open **index.html** in a modern browser (Chrome, Edge, Firefox or Safari).
3. Keep `index.html`, `styles.css`, `topics.js`, `test-bank.js`, `flashcards.js`, `study-materials.js`, `scenario-bank.js`, `sutton-bank.js`, `progress.js` and `app.js` together. No installation,
   server, internet connection or service worker is required.

Lessons, search, topic quizzes, mixed practice, tests, flashcards, scenario
practice, school-format practice, exam tips and study materials work directly
using `file://`.
JavaScript must be enabled. On mobile, use a browser that supports opening local
HTML folders; a file manager's HTML preview may not run scripts. A desktop browser
is the most reliable direct-file route.

Studied lessons, best topic scores, completed results, flashcard ratings and
planner settings are saved in browser local storage when
available. Direct-file storage behaviour varies by browser and file location.
When storage fails the site displays a warning and retains progress only for the
current visit. Moving the folder, using private browsing or clearing browser data
may remove progress. “Studied” is self-reported, not a mastery assessment.

## Use the site

- Choose Maths or English and browse or search topics.
- Read key ideas, follow the worked example and try the three practice questions.
- Select an answer and choose **Check answer** for an explanation; continue to
  see your result. Topic sets retain the best score.
- Mark a lesson studied when ready. You can undo it or reset all progress.
- Mixed practice draws 5, 10 or 15 shuffled questions from the same bank, optionally
  restricted to one subject. It is untimed; completed sets now save to Progress.
- English mixed questions include their passage in an expandable panel.
- Use the browser's print command to print a lesson; use paper for working.

## Practice tests

Choose **Practice tests** in the navigation or on the overview. There are three
subject modes: **Maths**, **English** and **Mixed**. The default is 20 questions
(mixed has 10 Maths + 10 English). Extended sets have 36 Maths, 24 English or
40 mixed questions (20 per subject). They draw from a separate original bank of 36 Maths and
24 English questions, not the short-practice bank. Subject tests select at least
one question from each of their lesson topics before adding extras; mixed tests
sample topics in each subject. Question order and selection are shuffled.

**Untimed is the default accessible alternative.** Optional 15, 25 or 40 minute
timers are personal practice settings, not official exam durations. The clock
continues on other pages, during submission confirmation and while the tab is
inactive. Expiry submits automatically, without a confirmation, and blanks earn
zero marks. The timer uses the device clock and checks elapsed time rather than
counting callbacks; browser suspension can delay displaying results until the
page resumes. Keep the device clock accurate. Reloading or closing abandons an
unfinished test; it does not save active answers or the active timer.

Read the instructions before starting. Use paper for working and practise Maths
without a calculator. Use Previous, Next or the question map to skip, return to
or change answers. The map distinguishes answered, unanswered and current
questions; it does not reveal correctness. **Clear answer** removes a choice.

**Review & submit** shows an explicit confirmation, including unanswered question
numbers. Return to fill them in, or submit with them blank. Final submission locks
the answers. Each correct answer earns one mark; wrong and unanswered responses
earn zero with no deductions. Results show the raw score, percentage, correct/
incorrect/unanswered counts, and a complete review with explanations and links
back to relevant lessons. Passages remain available in answer review.

Retry resets all answers for the same questions. Choose a new test to draw
another set; the finite bank means questions may repeat. Navigating to lessons
and back keeps an unfinished test **for this visit only**. Reloading or
closing abandons it. Completed results save to **Progress** and can be reviewed
after reload. Tests do not change stored lesson progress or short-
practice scores. These are original practice exercises, not official provider
papers, standardised scores or predictions of admission.

## Flashcards

Choose **Flashcards** in the navigation or overview. There are 154 original
recall cards: 60 general topic cards (36 Maths and 24 English, two for each of
the 30 lessons) and 94 additional cards tagged to SET, NWSSEE Stage 2, Tiffin
Stage One, Tiffin Stage Two or shared recall. Every card links to a known topic.
Filter by exam format, subject or topic. Cards contain substantive answers and
explanations and use prompts separate from the practice tests.

Try recalling the answer before choosing **Reveal answer**. **Hide answer** folds
it away again. After revealing, choose **Know it** or **Practise again** to record
your own judgement and move to the next unassessed card. These choices are not
automatic marking or proof of mastery. Previous/Next let you skip or revisit
cards without rating; revisiting a rated card lets you change its rating.

**Shuffle deck** changes the order and hides the answer while preserving ratings.
After all cards are assessed, the summary offers a round containing only
**Practise again** cards, or **Restart selected deck** for a fresh full round.
If no cards need another round, that button is disabled. Changing subject/topic
starts a fresh round, but does not erase saved ratings.

Your filters, deck order, revealed answer and current round remain when you visit
a lesson or test and return, **for this visit only**. Saved self-assessments now
survive reloads when storage is available. Changing filters/restarting clears
the current round, not saved ratings. Use **Only saved "practise again" cards**
to target these cards later. Flashcards do not change lesson/quiz progress or test attempts.
All controls work with keyboard focus and Enter/Space; there are no hidden
swipe-only gestures or network requirements.

## Original exam-style scenarios

Choose **Scenarios** in the navigation or overview. The bundled bank has 32
original situations—16 Maths and 16 English—with 64 explained subquestions.
Filter by subject, lesson topic and scenario type. Practise a scenario as a
short guided set: each question shows the shared context, immediate feedback
and a worked explanation. Completed answers contribute to saved topic
evidence, results and the existing mistake-revision and backup features.
Repeat a set or start a different filtered scenario. Completed attempts stay
local; leaving this page or changing filters abandons an unfinished set.

Print the currently filtered scenarios for paper practice. Each scenario's
answer key and explanations print after that scenario on a separate page.
Nothing is labelled by a historical year or provider. These are newly written
examples using common preparation formats, **not actual questions from the
previous ten years** or a substitute for provider guidance. The bank is finite,
and questions may be repeated in later practice.

## Girls' exam guide and school-format practice

Open **Girls' exam guide** for the two-stage routes at Tiffin Girls', Nonsuch
and Wallington High School for Girls. Its headline is the girls' pathway; the
shared SET is briefly distinguished from the boys' schools' separate second
stage. The guide links official sources and labels expected dates as provisional.
It does not predict pass marks, standardised scores or offers.

The shared SET is described as multiple-choice Maths and English, broadly
Key Stage 2, using a separate A–E lozenge answer sheet. Published guidance says
there is no verbal or non-verbal reasoning, calculator, rough paper or negative
marking. The expected date for the 2028-entry SET is Tuesday 14 September 2027;
check current school guidance. SET English select-two questions require both
correct choices. For other multi-select questions with an unspecified number
of answers, the official partial-marking method is unpublished, so practice
uses an explicitly stated exact-match rule.

The guide distinguishes:

- **Nonsuch/Wallington Stage 2 (NWSSEE):** written Maths and English, neither
  multiple choice; both parts must be passed. Published guidance for its stated
  cohort combines its marks with half the SET aggregate, with equal weighting
  between the two Stage 2 parts. The 2028-entry date was not published in the
  guidance checked.
- **Tiffin Stage One:** English multiple choice; Maths includes multiple-choice
  and digit-entry answers, including four-digit 24-hour times such as `0705`.
  The practice interface is not an official OMR sheet. The expected 2028-entry
  window is autumn 2027; check the school's website for dates and instructions.
- **Tiffin Stage Two:** written comprehension and creative writing in English;
  Maths final answers go on an answer sheet, and Tiffin guidance says working is
  not marked. Papers change yearly and no past papers are published.

As checked on 31 October 2026, Wallington High School for Girls' live Year 7
page says SET registration for September 2028 entry opens on 1 May 2027 and
lists an open evening on Tuesday 6 July 2027. The girls' autumn 2027
second-stage date was not published. Tiffin's live page still lists the
September 2027-entry cycle and 2026 test dates; do not carry these dates forward
as 2028-entry dates. Its 2028-entry dates remain unpublished (autumn 2027 is
only the expected window). Tiffin's previous Stage Two date of 7 November 2026
is for the older entry cohort, not the 2028-entry cycle.

Tiffin's published guidance also describes Year 5 curriculum assumptions,
unfamiliar formats, age-weighted standardisation, priority areas and the
school's published intake. These details can change: read the relevant
admissions policy and verify address eligibility directly with the school.
Stage One invitation is not an offer. The practice bank contains **133 SET
questions**, **24 Tiffin digit-entry questions**, **20 original unfamiliar-
format Maths items**, **30 written Maths problems** (10 with at least three
method marks), **four original Stage 2 reading passages with 16 questions**,
and **eight scaffolded writing prompts**. A topic-by-stage matrix on the
Sutton practice page shows question counts and gaps in that bank.

All practice is newly written and labelled as original; it does not reproduce
or paraphrase official samples or commercial papers. It is not a forecast,
complete archive or guarantee of success. School arrangements and coverage
vary, so read the current guidance before the exam.

## Study materials

Choose **Study materials** in the navigation. The revision-sheet selector
covers all 30 topics and reuses each lesson's summary, key ideas, worked
example and common pitfall. The 30 subject reference cards give concise Maths
methods/formulae (18 topics) and English comprehension, vocabulary, spelling,
grammar, punctuation and writing reminders (12 topics). These are quick
references, not a replacement for the complete linked lessons.

Three original passages (at least 150 words each) each have four interactive
comprehension questions with feedback and explanations. Their answers join the
same saved evidence and targeted revision system as other completed practice.
Six original story, descriptive, persuasive, article and report prompts include
planning steps and a transparent self-check rubric. The rubric is for the
learner to reflect on; extended writing is not automatically graded.

Choose any topic for a printable worksheet using its three original lesson
questions. **Print worksheet & answer key** places the explanatory answer key
on a separate printed page. The browser's normal print dialog controls paper
size and destination. Worksheet questions are reused, not counted as additional
unique questions. Print revision sheets, the reference cards and writing plans
as needed. No paper or online connection is required to use the materials.

## Progress, targeted revision and backup

**Progress** records the latest 100 completed practice, test and revision sets.
All answers are retained as question identifiers and chosen option indices;
scores and topic accuracy are calculated from those answers, not imported
claims of a score. Blank test answers count as zero. Repeated questions count
again, so this is practice evidence rather than a fresh-exam prediction.
Topics with no completed answers show **No recorded answer evidence**. Small
samples are explicitly uncertain. Historical best scores and self-reported
studied lessons are kept separately from tested accuracy.

**Revise mistakes** selects questions whose latest retained response is wrong
or blank. A later correct response removes a question. It uses up to 60 questions
per round; repeat if more remain. A result also offers revision of its wrong/blank
answers. **Practise-again flashcards** uses saved self-ratings, not tested accuracy.
Starting revision or opening an old result replaces an unfinished test without
recording it; normal page navigation otherwise leaves the timer running.

**Export backup** downloads a local JSON file; **Import** validates before an
explicit replacement confirmation. Imports replace rather than merge and close
any active tests/decks. Version 2 backups accept only known topics/cards/questions,
valid answer indices, bounded result history and real planner dates. Malformed,
unknown, oversized (over 1 MB) or unsupported data reports an error and leaves
current data unchanged. Old saved lesson progress is migrated locally. Imported
answers are unverified user data, not certified examination evidence.
**Reset all progress** requires confirmation; export first to retain a copy.
No backup is uploaded or sent anywhere. Storage failures are visible, and export
still works for visit-only data. Protect your backup locally.

## 2027 study planner

**Study planner** has an optional user-entered exam date in YYYY-MM-DD format and
1–7 sessions per week. Impossible dates and dates outside 2027 are rejected.
Leave the date blank until confirmed from current school/provider guidance.
It is an exam date, not a school entry date. No official deadline is supplied.

The planner suggests a flexible number of remaining topics per week, based on
your date and checklist. It also includes self-checked guidance, registration,
access-arrangement and exam-day preparation reminders. Completed topic checks
are planning decisions, not mastery marks, and persist separately from lessons.
Past dates are shown as passed rather than generating a false future schedule.
Keep sessions short, allow rest and adjust the plan to the learner's needs.

## Coverage and limits

Maths: number and negative numbers, operations, factors/multiples/primes,
fractions, decimals, percentages, ratio/proportion, algebra, sequences,
measurement/units, time/money, angles, shapes/nets/symmetry,
perimeter/area/volume, coordinates/transformations, data/averages, probability
and multi-step word problems.

English: comprehension, inference, evidence/purpose/viewpoint, vocabulary in
context, synonyms/antonyms, spelling/homophones, word classes,
sentences/clauses/agreement, tenses/voice, punctuation, literary devices/poetry
and writing/planning/editing.

This is broad foundation coverage, **not a claim to cover every school or exam**.
Depth, formats and writing requirements vary by school and exam provider.
Check the target school's current guidance. Verbal and non-verbal reasoning
are not included as separate subjects. The site includes lesson and test-bank
questions, 12 foundation reading questions, 64 scenario subquestions, and the
school-format banks described above. This is useful original practice, not an
exhaustive exam bank or a ten-year archive of real papers; worksheets reuse the
lesson questions. Writing practice here
teaches planning and editing through examples and objective questions; it does
not automatically grade extended written responses.

## Development

Edit `topics.js` for lessons and short practice, `test-bank.js` for the separate
test bank, `flashcards.js` for recall cards, `study-materials.js` for reference
notes, longer passages and writing prompts, and `scenario-bank.js` for original
scenario contexts and linked questions. `app.js` controls
navigation, materials, practice, tests and progress; `progress.js` defines the
strict backup schema and evidence calculations;
`styles.css` includes responsive,
reduced-motion and print styles. All scripts are classic deferred scripts.
Preserve local relative asset paths and avoid `fetch`, module imports or remote
resources so the direct-file route remains functional.

Check content structure, answer keys and absence of remote runtime resources:

```sh
node tests/content.test.cjs
node tests/practice-tests.content.cjs
node tests/flashcards.content.cjs
node tests/preparation.content.cjs
node tests/study-materials.content.cjs
node tests/scenarios.content.cjs
node tests/exam-readiness.content.cjs
```

For optional browser regression checks, install Playwright in your development
environment and run `node tests/browser.test.cjs`. It exercises the site through
`file://` with networking disabled, including all answer flows and responsive
routes. `PLAYWRIGHT_MODULE` may point to an existing Playwright installation;
`ARTIFACTS_DIR` may name an existing output folder for screenshots. Neither test
tool nor Node.js is required to use the website.
Run `node tests/practice-tests.browser.cjs` with the same optional variables to
check full test navigation, submission, review, unanswered questions, repeats,
offline operation and test layouts.
Run `node tests/flashcards.browser.cjs` with the same optional variables to
check filtering, reveal/hide, navigation, shuffle, self-assessment and deck-end
states through the offline direct-file route.
Run `node tests/preparation.browser.cjs` with the same optional variables for
timers, extended sets, persistent results, revision, planner and backup checks.
Run `node tests/study-materials.browser.cjs` for materials, worksheet printing
and comprehension interactions.
Run `node tests/scenarios.browser.cjs` for subject/topic/type filtering, contextual
answers, saved evidence, print answer keys, repeat attempts and offline responsive use.
Run `node tests/exams.browser.cjs` to exercise the girls' guide and tips, numeric
Tiffin answers (including leading-zero time), SET select-two scoring, NWSSEE and
Tiffin Stage 2 written practice, self-review, coverage matrix and responsive
offline behaviour.
